# DSA in Java – Part 09: Binary Search Tree (BST)

This repository contains my Java implementations and problem-solving practice focused on **Binary Search Trees (BST)**, covering important concepts, operations, and coding problems.

## 📚 Topics Covered

- Binary Search Tree Fundamentals
- BST Creation and Implementation
- Insertion in BST
- Searching in BST
- Deletion in BST
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Finding Minimum and Maximum Elements
- Inorder Successor and Predecessor
- Validating a Binary Search Tree
- Lowest Common Ancestor (LCA)
- BST-Based Coding Problems

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Binary Search Tree, Recursion, Tree Traversals, Binary Trees

## 🎯 Learning Objectives

- Strengthen understanding of Binary Search Trees.
- Implement important BST operations using Java.
- Improve recursive thinking and problem-solving skills.
- Practice tree-based DSA questions.
- Understand efficient searching and traversal techniques.
